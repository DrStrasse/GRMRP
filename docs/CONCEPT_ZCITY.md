# Концепт: Z-City / Homigrad → GRM (не внедрять целиком)

Источник: [uzelezz123/Z-City](https://github.com/uzelezz123/Z-City)  
Лицензия: AGPL-3.0 — **в `lua/` GRM не копировать**. Это референс механик, не аддон.

Z-City — форк Homigrad: урон по телу, своя оружейная база, рагдолл («fake»), инерция, одежда, физические пули, организм. Это **тактический симулятор тела**, не RP-документы и не фракции.

## Что из этого имеет смысл для GRM (позже)

### 1. Кровь на земле (заказ: «чтобы капало»)

Сейчас у нас `GRM_Bleed` — число в NW, тик урона, перевязка. **Визуала капель нет.**

Концепт GRM, не копия Z-City:

- Пока `bleed > порог` и игрок стоит/идёт — раз в N секунд след на полу (`util.Decal` / тонкий `env_sprite` / свой `grm_blood_drop`).
- Интенсивность от силы кровотечения: лужа гуще, интервал короче.
- Клиент рисует, сервер решает «капает / нет» (античит + лимит энтити).
- Следы живут 1–3 минуты, потом гаснут. Не спавнить сотни пропов.
- В воде / в машине — не капать.
- Связать с уже существующим bleedout (911 / подъём): пока лежит — лужа растёт под телом.

**Не тащить:** gibs мозга, musket-bleeding, их сеть организма.

### 2. Органы — только если RP это ест

Z-City считает печень/лёгкие отдельно. Для нашего RP достаточно:

- зоны: голова / торс / рука / нога;
- нога → хромает, рука → хуже стрельба/обыск, торс → bleed, голова → нокдаун.

Медкарта и 911 уже есть — зоны должны писаться в карту как запись врача, не как симулятор хирургии.

### 3. Не брать в GRM

- Всю оружейную базу и recoil-камеру.
- Рагдолл-фейк как основной локомотив (у нас ragdoll админский + bleedout).
- AGPL-код и бинарники `lua/bin`.
- Их админку, чат, Discord RPC.
