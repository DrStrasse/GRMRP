# Концепт: TempleOS-GLua → служебные ПК GRM

Источник: [HolidayLarp1225/TempleOS-GLua](https://github.com/HolidayLarp1225/TempleOS-GLua)  
Описание автора: «side joke» — терминал в мире, имитация TempleOS. AGPL-3.0, **не копировать аддон**.

## Что это

Энтити `ent_templeos_terminal`: экран в мире, фокус камеры (`holylua_terminal_view`), набор команд как у ОС.

Команды из README:

- система: `help`, `clear`, `shutdown`, `reboot`, `version`, `pwd`;
- файлы: `dir`/`ls`, `cd`, `cat`, `edit`, `del`, `mkdir`, `tree`, диски;
- «божественные» генераторы: `god` (стих), `godspeak`, `godbits`, FIFO/random как у Терри;
- звук: `music`, `beep`, `snd`;
- инфо: `memrep`, `date`, `time`, `cpurep`.

Плюс загрузка (boot screen), файловый менеджер, «kernel panic».

## Зачем нам это (не шутка целиком)

Наши ПК (`grm_comp_*`) — меню кнопок. TempleOS даёт другой язык: **консоль в мире**.

Имеет смысл для GRM:

1. **Режим «терминал»** на уже существующих компах (госбаза, военкомат, пожарка): чёрный экран, ввод строки, лог.
2. **Файловая метафора** под документы: `ls дела`, `cat паспорт SteamID`, `cd фракция` — не библия, а реестр.
3. **Boot / lock** как RP: ПК грузится 1–2 с, пароль отдела, «паника» при взломе.
4. **Камера к монитору** — опционально, как их convar: сел за стол, взгляд на экран.

Не тащить: Библию, GodSpeak, гимн TempleOS, чужие шрифты/звуки без лицензии.

## Как стыковать с текущим

- Не новый класс на каждый ПК. Один слой `GRM.Term` поверх `sv_grm_comp_terminal.lua`.
- Команды = те же net-операции, что кнопки (журнал пожаров, выдача прав).
- Лог сессии писать в аудит (кто сидел, какие запросы).
- Доступ как сейчас: фракция / CompAccess / служба.

Шуточный «храмовый» скин — только если будет отдельная фракция/пасхалка, не вместо госПК.

## Статус

Референс UI. Внедрять после квестов и только если нужен текстовый ввод на компьютерах, а не ещё одно DFrame.
