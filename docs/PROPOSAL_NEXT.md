# Сводка изученного и что брать в GRM

Не копировать чужие аддоны (AGPL Z-City / TempleOS, VEIN, LVS/simfphys). Только свои модули и идеи.

## Уже стоит в GRM — не ломать

HUD (вес, жажда, сытость, цвета), персонажи (пол, citizen-сетка, лимбо), фракции/форма/ксива, служебные ПК, гараж+дилер+номера+ключи, двери со своим persist, 911 (E = подъём), документы/нетеряемые, автоматы+инкассация, квест-студия, вес от еды.

Дыры: кровь без капель; паспорт не берёт пол автоматически; старые ПК без списка фракций; удостоверения, испорченные до фикса, сами не откатятся.

## Чужое: брать идею / не брать код

### Двери (SYSTEMS 4 / VEIN)

У нас уже владельцы, фракции, связки створок, `/door_access`.

| Взять как идею | Не брать |
|---|---|
| Гость с таймером | DarkRP jobs, ключи по нику |
| Квартира = пачка дверей, одна цена, подсветка | Обязательный SWEP ключей |
| Выбить замок → «сломан» до ремонта | Persist по модели+xyz |
| Замок с прогрессом + жест, не мгновенный клик | Их GUI на 3k строк |
| Короткий стук в дверь | Свои деньги VEIN |
| Автозакрытие служебных | |

### Транспорт (SpaxscE / LVS / simfphys)

Паки машин ставить **отдельными аддонами** на сервер. В zip GRM не паковать.

| Взять | Не брать |
|---|---|
| Бак на **UID** машины (petrol/diesel/electric) | Их колонки/пистолеты/API |
| Колонка: шланг, литры, оплата с кошелька | Armed / танки / SW / гонки |
| Канистра в инвентаре | Их HUD |
| Чужой тип → не заводится | |
| Расход от газа, пустой бак глушит | |

### Медицина (Z-City / Homigrad)

| Взять | Не брать (AGPL + другой жанр) |
|---|---|
| Капли/лужа пока идёт `GRM_Bleed` | Организм, органы, phys-пули |
| Под лежачим лужа растёт | Gibs, патогены, их HUD |
| Следы гаснут, лимит, не в воде/в авто | Fake-рагдолл целиком |

### ПК (TempleOS-GLua)

| Взять | Не брать |
|---|---|
| Режим консоли **на существующих** `grm_comp_*` | Шутку/Библию/их шрифты |
| Boot 1–2 с, пароль отдела | Отдельный класс на каждый ПК |
| Команды = те же операции, что кнопки | |

### Сквод из `comands.lua` (SYSTEMS 4)

Колесо приказов «иди / возьми / атакуй» — отдельно от дверей. Имеет смысл **позже** для полиции/армии, не сейчас. Не мешать с квест-диалогами.

## Что уместно добавить (своим кодом), по слоям

**A. Город живёт (высокий профит, мало риска)**  
1. Топливо: persist UID → расход → колонка с оплатой → канистра.  
2. Двери+: гость по времени, стук, выбивание+ремонт, прогресс замка.  
3. Кровь капает (уже заказано, отложено — когда скажешь).

**B. Службы**  
4. Консоль на госПК (поверх кнопок, не вместо).  
5. Паспорт подтягивает пол с `GRM_Gender`.  
6. Связать кассу автоматов с инкассацией фракции «как надо на карте».

**C. Не трогать, пока нет прямого заказа**  
Z-City организм, TempleOS как отдельная игрушка, VEIN целиком, LVS внутрь дистрибутива, сквод-приказы, капли если не просил.

## Рекомендуемый порядок внедрения

1. **Топливо v1** — бак+глушение+колонка. Сразу видно на сервере, стыкуется с гаражом.  
2. **Двери: гость + стук + выбивание.** RP жилья без смены ядра дверей.  
3. **Кровь на земле** — когда скажешь «сейчас».  
4. **Консоль ПК** — косметика служб.  
5. Всё остальное — по живому заказу.

## Жёсткие правила

- Не мержить чужие zip в `lua/`.  
- JSON только `util.JSONToTable(txt, false, true)`.  
- Ключ персонажа `SteamID64:charN`, машины — существующий UID.  
- После lua: синтаксис + `build_dist.py`.
