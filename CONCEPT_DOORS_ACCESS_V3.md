# GRM Doors Access v3 — матрица ордеров / тарана / категорий

**Дата:** 2026-08-13 · **Статус:** принято, код в `sh_grm_doors_access.lua` v3.0.0  
**Не трогает:** FFD, Q-меню, ядро `sh_grm_doors.lua` (слои EvaluateAccess уже v3)

## 1. Зачем

Ядро дверей переписано (v3.0.0). Матрица `/door_access` осталась палимпсестом v2.2.1:

- `/door_access` открывался только суперадмину, хотя `NET_SAVE` пускал `CanManage` — менеджер категорий не мог войти, зато теоретически сохранял всю матрицу;
- Steam-списки и ранги/отделы «Управления» жили в JSON, в UI их не было;
- `AlarmFriendlyCategories` проверялся, галочек не было;
- персист без version / карантина / read-back;
- таран после v3 смотрел `rec.owner_sid` — ордер на хозяйскую дверь больше не открывал таран.

## 2. Три контура (не путать с R-меню)

| Контур | Кто правит | Что даёт | Чего НЕ даёт |
|---|---|---|---|
| Ордер | SuperAdmin в `/door_access` | `/warrant`, ключ на **запертую** дверь хозяина | таран сам по себе, админку карты |
| Таран | SuperAdmin | выбить дверь (`CanForceDoor`) | ключ на E |
| Управление | SuperAdmin выдаёт; сам `CanManage` | открыть `/door_access`, категории | вкладку «Администрирование» на R |
| Карта (R) | только SuperAdmin | фракция/категория/ownable | — |

`AM.CanManage` ≠ админка двери. Это слой 5 ядра, не матрица.

Терминалы / штрафы / розыск — **другие** файлы (`grm_wanted/access.json`, `E.CanFine`). Сюда не входят.

## 3. Допуски меню

- Открыть `/door_access`: SuperAdmin **или** `CanManage`.
- Сохранить матрицу (ордер/таран/управление/сигналка/Steam): **только SuperAdmin**.
- Категории (создать/переименовать/удалить/фракции): SuperAdmin или `CanManage`.
- Менеджеру матрица на клиент не уезжает (нет Steam-списков).

## 4. Персист

`data/grm_doors/access.json`, `version=3`.  
Фракции/роли/отделы — карты (строковые ключи). Steam — **массивы** CharacterKey.  
Чтение `jsonT(..., false, true)`. Битый файл → карантин `.corrupt.<ts>`, не затирать. Read-back после записи.  
Старый файл без version поднимается как есть.

## 5. Контракт наружу

`CanManage`, `CanWarrant`, `CanForceDoor`, `IsFriendly`, `OpenMenu`, `Load`, `Save`, `Data`, `Evaluate`.  
Каналы `GRM_DoorAccess_*`. Команды `/door_access`, `!door_access`, `grm_door_access`.  
Вкладка «Двери и Ордера» в `/factions` (через `OpenAdminMenu`, глобал не локализуем).
