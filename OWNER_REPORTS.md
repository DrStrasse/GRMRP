# ОТЧЁТЫ ВЛАДЕЛЯ И ЖУРНАЛ ПОДТВЕРЖДЁННЫХ ОШИБОК (GRMRP)

**Обязательно к прочтению каждому агенту ДО правок.** Единый MD по указанию
владельца (03.09 вечер-13): здесь — дословные отчёты, доказанные корневые
причины, принятые решения и правила. Не домыслы: каждая строка подтверждена
кодом/стендом. Новые записи добавляет каждый, кто чинит; молчать нельзя.

## 0. Постоянные приказы владельца (не пересматривать без него)

1. Каждый раунд заканчивать: коммит → push в `arena/*` ветку сессии → **обе**
   dist-ссылки (`dist/grmrp_gamemode.zip` И `dist/grm_full_code.zip`).
2. Чат EasyChat вырезан ВЕЗДЕ (×4 повторений, вечер-13 финал): ни одного
   живого вызова `EasyChat.*` в контуре GRM. Осталось только в мёртвых
   комментариях-уроках — грепить СТРОКУ ВЫЗОВА, не слово.
3. Своя система: своя библиотека, свои правила, свои чаты. Все модули
   (документы, образование, спецслужба, бюллетени, обмен розыска, биндер,
   HUD) ходят через GRM-шины: `GRM.RPBroadcast`, `GRMRPChat.SendText/
   RegisterExternalChatCommand`, `GRM.Chat.DispatchFactory`. Не изобретать
   развилки заново в модулях.
4. Никаких выдумок об API движка: новый метод панели/скролла — только после
   грепа gsrc (garrysmod/lua). Подтверждённые фантомы см. §2 веч.-7/12.
5. Self-evidence оттиском сборки: жалоба «починено/не починено» закрывается
   штампом в баннере (`чат GRM · сборка вечер-N (дата)`), `/chatdiag`,
   `grm_money_diag`. Скриншот со старым оттиском = старая сборка, не баг.
6. «Зелёный стенд» ≠ «работает»: проверять БОЕВОЙ файл стендом, который его
   исполняет (sv-логику — sim_chat_sv_routing, грузящий реальный
   sv_grmrp_chat.lua). Статические грепы — только контракты/строки.
7. Нейрослоп запрещён: без мёртвых веток, дублей кода, условных проверок
   `x == 1 or true`, комментариев-отписок вместо логики, CJK-огарков и
   тайпо в именах проверок. Диф читается глазами перед коммитом.
8. Enter отправляет с первого нажатия; полоса ввода полностью видима;
   настройки = стандартный диалог движка; тик/клавиша в селекторе СРАЗУ
   меняют оружие; кнопки меню украшать, но не подменять функционал.
9. Деньги: наличка + счёт на постоянно видимом месте (кассеты «СОСТОЯНИЕ»
   v10.7+ и карточка меню «На счёту»); при жалобе сначала `grm_money_diag`.

- (вечер-14, СТОЙКОЕ) чат — отдельная библиотека `lua/grm_chat` по образцу
  EasyChat: тонкий лоадер + папка модулей; машиногенные дубли-порты
  недопустимы; режим ест библиотеку форвардерами/бандлом (байтовое равенство —
  гейт). Единственный источник кода — `lua/grm_chat/`.

## 2. Журнал подтвержденных ошибок (корень → фикс → доказательство)

- **веч.-5.** `SetSkin`/`GetModel` фантомы у DModelPanel → крах меню. Чинено по
  dmodelpanel.lua. Правило: греп движка перед «новым методом».
- **веч.-6.** Штампы строк ленты на RealTime() при curTime-возрасте → строки
  «протухали» на лету. Фикс: одни часы CurTime. Стенд sim_chat_clocks.
- **веч.-7.** `GetCanvas()/SetReadOnly()` на чужих классах; часы ленты. Фантомы
  выпилены, стенд запрещает строки вызова.
- **веч.-8.** Витрина персонажа: только SetSkin/SetBodygroup/turntable.
  Введён оттиск сборки + /chatdiag.
- **веч.-9.** Лента в HUDPaint уезжала за край на чужом HudScale → лента =
  derma-панель.
- **веч.-10.** «История мелкая» → clamp-размеры; скролл к концу —
  `ScrollToChild` (канон DPanelList), НЕ `VBar:GetCanvas` (фантом).
- **веч.-11.** Деньги под tool-HUD (он рисуется поверх попопов) → нижние
  кассеты панели «СОСТОЯНИЕ», которые нечем задавить.
- **веч.-12.** `EditablePanel:Close()` — фантом (только DFrame) → креш окна
  истории; «хранение» читало TTL-кормовую ленту (~49 с) → отдельный архив +
  JSON в DATA + wallT; строки биндера без эха автора → `GRMRPChat.SendText`;
  чужие slash съедались net-каналом → роут через say + `_inExternal`-гейт
  ре-ентери.
- **веч.-12.2.** Память ввода не переживала рестарт → `grm_chat/input.txt`;
  климп 512 резал кириллицу → `Utf8Cut`; окно не прилипало к низу → VBar
  `GetVBar():SetScroll(maxScroll())` по dscrollpanel.lua; флеш на Shutdown.
- **веч.-13. КОРЕНЬ «всех тех же ошибок».** Guard порта
  `if GRMRP and GRMRP.Version then return end` исполняется в lua/autorun, а
  GMod грузит аддоны ДО файлов режима — условие ЛОЖНО ВСЕГДА. На живом сервере
  жили до ТРЁХ чатов: режимный, порт GRMChat и СТАРЫЙ `sh_grm_rp_chat.lua`
  (его PlayerSay возвращал `""` — съедал строки; лента — вторым слоем через
  chat.AddText). Фикс: `GRMRPChat.SuppressAddonPort()` (снятие хуков по
  префиксам `GRMChat*`/`GRM_RPChat*`+команд, вызов на shared-стадии режима и
  страховками cl_init/sv) + гейты `SUPPRESSED` в хвостах порта + Initialize-
  снятие легаси в песочнице + изоляция DATA-файлов порта (`port_*`) + ранний
  guard по `GRMRPChat.Channels` для lua_refresh.
- **веч.-13. Реальные баги, найденные НОВЫМ стендом sim_chat_sv_routing**
  (до него sv-логика не исполнял ни один стенд — потому и жили):
  1. `RPAction` не имел ветки `me` → `/me` не видел НИКТО, кроме автора;
  2. `includeAuthor` в `deliver` был ложью (автор уже исключён в
     ResolveAudience) → /it /try /roll не видел даже сам автор (клиент ждёт
     серверную строку);
  3. `ResolvePmTarget` сравнивал `tostring(ply.Name)` (функция!) → /pm по нику
     не работал никогда, только по SteamID64;
  4. одинокий `/me` без тела слал «* Ник » на весь сервер → теперь подсказка;
  5. у dead-канала не было алиаса `/dead`;
  6. порт в песочнице падал на `GRMChat.Enabled()` (функция жила только в
     shared.lua режима) → фолбэк в CORE_HEAD генератора;
  7. документы/образование держали две копии трёхветочной развилки
     EasyChat/GRM_RPChat_Msg/ChatPrint → вырезаны в пользу `GRM.RPBroadcast`.

- **веч.-14.** Чужие хуки подавителя не снимались НИКОГДА (продакшн-баг с
  момента написания SuppressForeignChat): `string.find(id, "^GRMChat", 1,
  true)` — в plain-режиме `^` литерал, совпадений ноль. Фикс: честный
  префикс `id:sub(1, #pat) == pat`. Поймано ИСПОЛНЕНИЕМ в sim_chat_lib_arch
  (чужой GRMChat_Capture снимается, GRMRPChat_* живёт); грепом баг невидим.
  Там же закреплены контракты: подавитель не жрёт себя (`port == GRMRPChat →
  nil`), алиас GRMChat==GRMRPChat не дублирует доставку (шина встаёт на
  первом владельце). Отдельный урок генерации: форвардер режима на секунду
  родился кодом ВНУТРИ `--[[ ]]` — любой машиногенный вход читается глазами
  после записи. «Нет net-отправки автору» в соло-мире — не баг: deliver
  исключает автора (оптимистичное эхо); для проверки доставки нужен второй
  слушатель.

- **веч.-15.** «Привязка к старым модулям» оказалась НЕ только в ветке
  EasyChat (вырезана веч.-13), а в самой последней трети автоотыгровок:
  nameplate/pcboard/911 печатали «* …» движковым ChatPrint — на GRMRP-сервере
  это строки МИМО своей ленты/архива/каналов (=фактически «в никуда», т.к.
  ванильная панель скрыта мостом-гейтом). УРОК: аудит «завязок» обязан
  искать ЛЮБУЮ генерацию «* » и любой ручной аудитори-цикл, а не только
  имена чужих модулей; греп по «EasyChat» даёт ложное чувство чистоты.
  Фикс: все точки — на `GRM.RPBroadcast` (новая адресность: Player/список/
  {radius,targets,echoAuthor,rpName}); `deliver(forcedTargets)`; ветка
  `GRM_RPChat_Msg` из шины вырезана. Доказательства: sim_rp_bridge (досье:
  net.Start не вызывается), sv_routing (+5 рантайм-тестов forced-аудитории),
  clocks (+7 стен против возврата ручных циклов). Маска: rpName из модуля,
  шина НЕ подставляет настоящее RP-имя в masked-события (деанон-баг
  предотвращён стендом).

## 4. Контракты, зафиксированные стенами (менять только с приказа владельца)

- (веч.-14) ЕДИНСТВЕННЫЙ код чата — `lua/grm_chat/` (лоадер
  `lua/autorun/grm_chat.lua`). Режим: `modules/chat/*` = форвардеры
  (аддон → `grm_chat/`, соло → `lib/grm_chat/` байтовым близнецом).
  `GRMRPChat` — канон, `GRMChat` — алиас того же стола; машиногенные дубли
  (namespace-порты) запрещены. Идемпотентность файлов — флаги __core/__sv/
  __hud/__inp. Уступки режиму — маркеры `GM.__chatOwnsPlayerSay` /
  `GM.__chatOwnsStartChat`; библиотечные входы — hook PlayerSay
  `GRMRPChat_Capture` и HUDKeyPress `GRMRPChat_Y`.
- (веч.-14) `SuppressForeignChat` сравнивает ПРЕФИКСЫ строкой (`sub`), а не
  lua-паттернами; свои id (`GRMRPChat_*`) матчу не подлежат; снятие
  конкоманд щадит помеченные `GRMRPChat.__cc`.
- (веч.-15) Серверная RP-отыгровка («* Имя действие») генерируется ТОЛЬКО
  через `GRM.RPBroadcast` (адресность: number | Player | {radius, targets,
  echoAuthor, rpName}); ручные циклы ChatPrint/player.GetAll в чужих форматах
  — нарушение (ловят clocks-стены). Легаси-канал `GRM_RPChat_Msg` из шины
  вырезан; фолбэк без владельца — движковый ChatPrint. Masked-события несут
  имя-легенду (rpName из модуля), не настоящее RP-имя.
- (веч.-14) deliver ИСКЛЮЧАЕТ автора (оптимистичное эхо клиента): «нет
  net-отправки автору» в однопользовательском тесте — НЕ баг; для проверки
  доставки заводи второго слушателя.

- `ScrollToChild` канон; `SetSize(math.Clamp(ScrW()*0.62,760,1400),
  math.Clamp(ScrH()*0.72,480,1120))` для окна истории; `Remove()`, не
  `Close()`, для нережимовых попопов; админка `SetKeyboardInputEnabled(false)`
  на мышиных панелях; селектор MAXSLOT=10+clamp; blur и «старые окна» через
  gameuiActivate/gamemenucommand; кассеты денег v10.7+; «На счёту» в карточке;
  лента: мирские каналы слышат только живые (веч.-8 политика, стенд pinned);
  dead-чат range 400; ladder 0.35/8/10s; HARD_MAX 512, cvMax 256.
