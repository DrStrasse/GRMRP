# GRM — Garry's Mod RP-сборка (DrStrasse)

Полнофункциональный набор Lua-модулей для roleplay-серверов Garry's Mod:
фракции, экономика, инвентарь, документы, служебные компьютеры, розыск и штрафы,
транспорт и топливо, логистика, маскировка, комендантский час, CCTV, прослушка,
пожарная служба, биржа труда, телефон, соц.анимации и биндер отыгровки.

> **Передача дел:** сначала `HANDOVER.md`, потом `ARCHITECTURE.md`.
> История правок — `CHANGELOG.md`.
> **Правила написания аддонов и модулей — [GRM_ADDON_GUIDE.md](GRM_ADDON_GUIDE.md)**
> (единственный свод: рендер, дублирование, оптимизация, сеть, UI, данные,
> стенды; чеклист нового модуля, справочник «симптом → причина → правило»).
>
> **Дом проекта — репозиторий [`DrStrasse/GRMRP`](https://github.com/DrStrasse/GRMRP).**

## Состав репозитория

## Установка

Основной аддон: `garrysmod/addons/grm/` из архива  
https://github.com/DrStrasse/GRMRP/raw/arena/01a05de8-grmrp/dist/grm_single_addon.zip  

Студия аддона — **отдельный аддон**: `garrysmod/addons/grm_addon_studio/` из архива  
https://github.com/DrStrasse/GRMRP/raw/arena/01a05de8-grmrp/dist/grm_addon_studio.zip  
В `grm_single_addon.zip` её нет (в `lua/` файлы студии не входят). Без
основного GRM студия открывается, но сохранение проектов откажет
(`no_grm_persistence`) — нужен установленный GRM.

Пожарный — в `garrysmod/addons/grm_fire/` (`dist/grm_fire_addon.zip`, если есть).

> **Важно при обновлении:** удалите старую папку `addons/grm` целиком и только
> потом распакуйте новую сборку. Копирование поверх оставляет мёртвые файлы
> (старый атлас даёт `'<eof>' expected near '='`).

Сборка архивов:

```bash
python3 tools/build_dist.py
```

## Что нового (сентябрь 2026)

- **Студия аддона `/studio`** — визуальный граф-редактор: блоки
  (модели, пропы, энтити, экраны, свет, постобработка, фото, звук,
  условия, таймеры, хуки, net, меню, кнопки, списки, команды), связи
  между портами, инспектор полей, 3D-вьюпорт с гизмо, снятие кадра,
  компиляция в черновик GLua — копируешь и присылаешь агенту.
  Доступ: суперадмин.
- **Игрок и мир:** узлы «игрок» (здоровье/броня/скорость/стамина/
  модель/цвет), «эффект» (тряска/флеш/частицы/impacts), «материал»
  (текстуры), «путь» (маршруты точек), «крепление» (родитель+локальные
  координаты), «чат»/«кнопки чата», «клавиши» (IN_/KEY_), «музыка»
  (зацикленный эмбиент).
- **Конструктор окон (вкладка «МАКЕТ»):** 12 видов виджетов — кнопка,
  текст, поле, текст-область, чекбокс, слайдер, выбор, список, картинка,
  **модель 3D (DModelPanel)**, прогресс, панель; перетаскивание,
  **ресайз за углы/рёбра**, прилипание к сетке 8 px, кнопки «В СЕТКУ»,
  «ЦЕНТР», «ДУБЛИРОВАТЬ», Delete; поля x/y/w/h и поля виджета с
  пикерами (модель/материал); «ТЕСТ ОКНА» — настоящее DFrame с
  рабочими виджетами; шаблоны макетов сохраняются в проекте.
- **Предпросмотр / предпоказ (кнопка в шапке):** окно с вкладками
  «СЦЕНА» (DModelPanel каждого визуального узла + кнопка «В 3D»),
  «МАТЕРИАЛЫ» (поиск по каталогу, увеличение), «ЗВУКИ» (▶
  прослушивание узлов и каталога), «КАДРЫ» (снятые снимки), «ТЕСТ
  ОКНА». В инспекторе узла — «▶ ПРОСЛУШАТЬ» (звук/музыка),
  «ПОКАЗАТЬ МАТЕРИАЛ/КАДР», а в 3D — режим «СЦЕНА» (все узлы сразу)
  и перебор «◀ ▶» по визуальным узлам.
- **Проверка (вкладка «ПРОВЕРКА»):** валидатор манифеста — несуществующий
  класс/модель/звук, битые порты, пустые обязательные поля, виджеты за
  краем макета — и синтаксис сгенерированного черновика.
- **Конструктор размещения:** узел «ЭКСПОРТ» с галочкой «тул + undo»
  компилирует готовый тул-файл (`lua/weapons/gmod_tool/stools/…`):
  ЛКМ — поставить собранный префаб, ПКМ — убрать, undo работает.

## GRM Core

Модули общаются через `GRM` и `Factions`. Фундамент: `GRM.Core`, `GRM.Lang`,
`GRM.Persistence`, `GRM.Access`, `GRM.Net`, `GRM.Audit`, `GRM.UI`,
`GRM.Identity` (`SteamID64:charN`), `GRM.Perf`.

Правила: состояние у персонажа, не у аккаунта; клиент шлёт намерение;
JSON — `util.JSONToTable(txt, false, true)`; деньги только через Economy API.

Полный инвентарь — `ARCHITECTURE.md`.

## Ключевые системы

- **Фракции** — структура, казна, `/fmenu`, комендантский час, маскировка, `/gnews`.
- **Экономика** — банки, банкоматы, налоги, зарплаты, инкассация.
- **Документы / 911 / медицина** — паспорта, лицензии, ранения, медкарта.
- **Транспорт** — дилер, гараж, автопарк, топливо, прочность, круиз.
- **Двери / недвижимость** — замки, ордера, аренда.
- **Службы** — логистика, биржа труда, телефон, CCTV, пожарка.
- **Отыгровка** — `/binder` (чат, консоль, позы), соц.анимации.

## Основные команды

**Игрок:** `/inv`, `/store`, `/fjoin`, `/fr`, `/dep`, `/gnews`, `/kom_hour`,
`/binder`, `/починить`, `/911`, `/property`, `/duty`.

**Админ:** `/factions`, `/fmenu`, `/permadd`, `/permremove`, `/animstudio`,
`/studio` (`/адонстудия`, `/addonstudio`) — студия аддонов,
`/salary_admin`, `/grm_access`, `!grmmenu`.

Полный список — `ARCHITECTURE.md`.

**Чат (EasyChat):** команды с ведущим `/` или `!`, не распознанные ни
одним модулем (например `!noclip`), выполняются локально как консольные
и **никогда не выдаются в глобальный чат**. Реестр известных команд —
`GRM.EasyChat.CmdList` в `lua/autorun/zz_grm_easychat_cmds.lua`: новую
чат-команду модуля нужно вносить туда (контролирует
`sim_easychat_unknown_cmd.lua` → `tools/luatest/`).

## Зависимости

- **ArcCW** — оружие.
- **simfphys / LVS** — транспорт (HP и топливо завязаны на simfphys).
- **ULX/ULib** — опционально.
- **vFire** — пожарка (`addons/grm_fire/`).

PAC3 / чужой LVS HP / TempleOS-консоль ПК в сборку не копируются.
