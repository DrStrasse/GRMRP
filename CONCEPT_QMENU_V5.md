# GRM Q-меню «Стройка» v5

**Дата:** 2026-08-16 · **Статус:** реализовано

## Безопасность

- Для обычного игрока Q-меню содержит только каталог `prop_physics`.
- Сервер жёстко блокирует ragdoll, effect, NPC, SENT/entity, SWEP/оружие и транспорт независимо от клиентского интерфейса.
- Суперадмин сохраняет полный административный доступ.
- Игроку показывается только безопасный строительный набор инструментов. Служебные GRM-тулы и опасные инструменты в его списке отсутствуют.

## Интерфейс

- Окно занимает 94% ширины и 92% высоты экрана, с пределом 1900×1040.
- Три рабочие области: большой каталог пропов, список инструментов, параметры выбранного инструмента.
- Вкладки: «Каталог», «Мои объекты», «Настройки».
- Параметры строятся только по ручным схемам; чужие `BuildCPanel` не исполняются.
- Для `colour`, `light`, `lamp`, тросов, шкивов, лебёдок, гидравлики, мышц, направляющих, шаров и трейлов используется полноценный `DColorMixer`.
- Реальные параметры штатных stool представлены своими контролами: `DNumSlider` для диапазонов, `DBinder` для клавиш, чекбоксы, выпадающие материалы/эффекты и текстовые пути моделей.
- Полные ручные схемы есть для weld/rope/pulley/winch/hydraulic/muscle/slider/axis/ballsocket/motor/wheel/thruster/hoverball/balloon/light/lamp/button/material/paint/trails.
- Настройки игрока: облегчённый режим без превью моделей и компактный режим. Суперадмин дополнительно видит серверные параметры каталога, лимита и доступа.
- Список фракций для `grm_duty_npc` приходит с сервера и отображается выпадающим списком, а не текстовым полем.

## Режим суперадмина

- Суперадмин персонально выбирает стандартное Q или кастомную «Стройку».
- Переключатель расположен в шапке и во вкладке «Настройки»; консольная команда — `grm_qmenu_admin_toggle`.
- Выбор хранится в клиентском `grm_qmenu_admin_vanilla` и не меняет режим других игроков.
- `/qm` открывает кастомное окно напрямую даже из стандартного режима, поэтому вернуться к «Стройке» всегда возможно.

## HOLD-Q

- Нажатие `+menu` открывает окно один раз.
- Пока Q удерживается, окно остаётся открытым.
- Отпускание Q закрывает окно.
- Повторный `pressed=true`, синхронизация конфига и Think не закрывают и не пересоздают окно.

## Совместимость

Сохранены `GRM.QMenu.Cfg`, `Save`, `Reload`, `CanSpawn`, `CanUseTool`, `CanOpenQ`, `ToolCatalog`, прежние net-каналы и формат `data/grm_qmenu.json`.
