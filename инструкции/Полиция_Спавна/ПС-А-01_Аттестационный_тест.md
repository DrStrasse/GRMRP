- в) телепортацию
- г) тип блока

- в) убийства
- г) команды

**15.** Параметр `a:container` (или `a:click`) — это:
- а) открытие/взаимодействие с сундуками и ёмкостями
- б) постройка
- в) вход на сервер
- г) телепорт

- в) ранг игрока
- г) режим

**17.** Для отката ущерба от гриферства используют:
- а) `/co i`
- б) `/co rollback u:Ник t:время r:радиус`
- в) `/kick`
- г) `/tp`

**18.** Координаты блока для запроса берутся из:

- в) чата
- г) ниоткуда, они не нужны
