# ПОЛИЦИЯ СПАВНА · ПС-Д-02

## Бланки план-заданий и протоколы (чистые формы)

```
╔══════════════════════════════════════════════════════════╗
║                П О Л И Ц И Я   С П А В Н А               ║
║                                                          ║
║   ГРИФ: ДЛЯ СЛУЖЕБНОГО ПОЛЬЗОВАНИЯ                      ║
║   ДОКУМЕНТ: ПС-Д-02                                     ║
║   ТЕМА: ЧИСТЫЕ БЛАНКИ И ПРОТОКОЛЫ                       ║
║   АДРЕСАТ: ДИСПЕТЧЕР, ПАТРУЛЬНЫЕ                        ║
╚══════════════════════════════════════════════════════════╝
```

> *«Форма экономит время и спасает от забывчивости. Заполняй её всегда.»*

**Как пользоваться.** Скопируй нужный бланк в служебный канал, Discord или тетрадь, заполни поля. Поля в квадратных скобках — обязательные. Незаполненное обязательное поле делает документ недействительным.

**Перечень форм**

| Форма | Наименование | Кто заполняет |
|---|---|---|
| **Б-1** | Бланк план-задания (универсальный) | Диспетчер |
| **Б-2** | Протокол о происшествии | Патрульный |
| **Б-3** | Протокол осмотра места происшествия | Патрульный |
| **Б-4** | Объяснение (опрос) | Патрульный |
| **Б-5** | Рапорт о выполнении план-задания | Патрульный |
| **Б-6** | Протокол задержания | Патрульный |
| **Б-7** | Журнал план-заданий | Диспетчер |
| **Б-8** | Протокол приёма-сдачи смены | Сдающий / принимающий |
| **Б-9** | Акт приёма-передачи материалов | Передающий / принимающий |
| **Б-10** | Рапорт о невозможности выполнения | Патрульный |

## ПАМЯТКА: ЧТО ОБЯЗАТЕЛЬНО В КАЖДОМ ДОКУМЕНТЕ

1. **Номер план-задания** — связывает все документы одного дела.
2. **Дата и время** — без них событие нельзя сопоставить с логами.
3. **Координаты (X / Y / Z)** — «где-то у спавна» не является адресом.
4. **Ники** — всех участников, свидетелей, составителя.
5. **Разделение факта и мнения** — в протоколе факты, в выводе оценка.
6. **Фиксация** — скриншот (F2) с координатами (F3), либо запись, почему фиксация невозможна.

> **Запомни:** незаполненный бланк стоит дороже заполненного. Пустая строка в протоколе — это вопрос, на который потом некому ответить.
