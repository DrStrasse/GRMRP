# Гражданский рынок транспорта — концепт v1

**Дата:** 22.08.2026  
**Решение владельца:** личная покупка выбирает оплату «наличные / счёт»; единый
рынок доступен и в отдельном гражданском транспортном компьютере, и у
торговца редкостями.

## 1. Два независимых контура

### Автопарк организации (`GRM.Fleet`)

- Деньги: бюджет фракции.
- Владелец: фракция.
- Единица: `FL.Units[id]`.
- Выдача: ведомственный гараж, назначенная роль/отдел.
- Позиция рынка доступна только явно указанной фракции либо подходящему
  уровню допуска; серверная проверка обязательна.

### Гражданский рынок (`GRM.CivilVehicles`)

- Деньги: персонаж выбирает наличные или банковский счёт.
- Владелец: `CharacterKey`.
- Покупка: создаёт личную запись существующего дилера/гаража, а не `FL.Units`.
- Позиция может быть `personal` или `public`; служебные и фракционные позиции
  никогда не видны и не покупаются через этот контур.
- Файл: `data/grm_vehicle_market/civil.json`; записи массивом, version/read-back.

Один класс машины может одновременно быть на обоих рынках, но это ДВЕ
отдельные позиции, цены и ограничения.

## 2. Права и безопасность

- Рынок редактирует только суперадмин (`vehicles.market.edit`).
- Клиент передаёт только `entryID`, `garageID`, `payment`.
- Сервер заново получает запись, CharacterKey, гараж и цену; проверяет:
  - `entry.kind == personal/public`;
  - доступ по фракции/лицензии, если заданы;
  - лимит класса;
  - доступность гаража и свободное место;
  - наличные/счёт до списания;
  - успешное сохранение личной записи до подтверждения покупки.
- При ошибке записи деньги не списываются либо транзакция откатывается.

## 3. Точки входа

1. `grm_civil_vehicle_computer` — новый гражданский транспортный компьютер,
   ставится service tool / пермится.
2. Тип торговца `vehicle_market` у `GRM.Vendor`: открывает тот же клиентский
   экран, но не дублирует данные/логику.
3. Дилер транспорта: на вкладке личного каталога показывает только позиции
   гражданского рынка, доступные покупателю.
4. Ведомственные компьютеры: существующая вкладка `GRM.Fleet.AttachTab` остаётся
   для фракционного автопарка. Она уже подключена к мэрии, полиции, военной
   полиции, армии, медицине, охране, автоинспекции и суду; недостающие
   компьютеры получат её отдельной интеграцией без копирования UI.

## 4. Интерфейс

- каталог карточками: 3D `DModelPanel`, название, класс, цена, лимит,
  статус доступа;
- поиск и категории;
- гараж назначения выбирается явно;
- в диалоге покупки две кнопки: «НАЛИЧНЫМИ» / «СО СЧЁТА»;
- на стороне клиента предпросмотр использует существующий
  `GRM.VehiclePrecache`, который подгружает source/simfphys/LVS модели
  порциями ещё при входе.

## 5. Очерёдность внедрения

1. Серверное хранилище/транзакция гражданского рынка + sim-тест.
2. Общий гражданский UI и `DModelPanel`.
3. Компьютер + service tool + persistence.
4. Вкладка торговца редкостями.
5. Интеграция с дилером и обновление документации/архивов.
